# Security

AgentValley reads the files Claude Code writes on your Mac, and reads your Claude Code login from the Keychain when you turn on Plan limits. If you find a way it could leak any of that, or anything else that puts a user at risk, please tell us privately.

## Report a vulnerability

Open the **Security** tab of this repository and choose **Report a vulnerability**. Please do not open a public issue for it.

We aim to answer within a week.

## Supported versions

Fixes go into the latest release only. The app looks for it once an hour; Check now in Settings looks at once.
